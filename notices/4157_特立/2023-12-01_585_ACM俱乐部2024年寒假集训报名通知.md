ACM俱乐部2024年寒假集训报名通知

发布日期：2023-12-01
编辑：张赞
审核：赵昊

为发展基地科技创新事业，鼓励同学们积极参加科技创新实践，培养具有高水平科技创新能力和优秀科创品质的高素质学子，ACM俱乐部决定开展2024年寒假集训，具体安排如下：

集训信息：

1. 面向对象：

全体2022级本科生、2023级本科生。

2. 集训安排：

2024年1月15日-2023年2月1日，具体时间待定。

3. 报名与选拔：

报名时间：即日起~2023年12月9日

报名地址：https://f.wps.cn/g/9KUCifeR/

选拔考试时间：2023年12月10日14:00-19:00

考试形式：ACM赛制。线上考试，考试过程中需全程开启摄像头、屏幕和手机监控，考试结束后ACM俱乐部将对所有监控材料进行分析并对提交程序进行查重，如发现作弊现象一律取消比赛结果。

我们将择优选拔进入寒假集训，请大家认真完成，诚信测试。

4. 内容安排：

针对2022级同学，寒假集训将进行实战演练，通过训练赛，提升做题的熟练程度。

针对2023级同学，寒假集训将讲解算法竞赛中常见的入门的知识技巧。

主要内容如下：

| 序号 | 内容 |
| --- | --- |
| 1 | 开训仪式,c语言复习与拓展 |
| 2 | STL的讲解与应用 |
| 3 | 排序,模拟,枚举 |
| 4 | 第一场积分赛 |
| 5 | 二分、三分、快速幂 |
| 6 | 贪心算法 |
| 7 | 图与搜索算法(bfs、dfs) |
| 8 | 拓扑排序、最短路 |
| 9 | 第二场积分赛 |
| 10 | 双指针、前缀和 |
| 11 | 单调栈、单调队列 |
| 12 | 矩阵快速幂、简单数论 |
| 13 | 第三场积分赛 |
| 14 | 动态规划 |
| 15 | 并查集和最小生成树 |
| 16 | 线段树和树状数组 |
| 17 | 复习 |
| 18 | 集训总结赛、闭幕式 |
