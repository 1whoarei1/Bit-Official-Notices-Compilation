关于公布2024年度物理学院院级教育教学改革项目立项结果的通知

来源：物理学院
发布日期：2024-11-08
原文链接：https://physics.bit.edu.cn/tzgg4/6f2a6e9d24d74749bb83121922471a82.htm

根据学校教育教学改革项目工作方案，学院组织开展了院级教育教学改革项目申报及评审工作，现将2024年度物理学院院级教育教学改革项目立项项目清单予以公布：

| 项目名称 | 负责人 |
| --- | --- |
| 深度学习融入凝聚态物理教学探索 | 周金健 |
| 《量子雷达开放型实验课程》课程设计与实验教学实践 | 张胜利 |
| 大学物理课程与人工智能神经网络融合的教学改革与实践 | 孙林锋 |
| “理工融合”下理科电子线路实验教改探索 | 何锋 |
| 科教融合-光学前沿融入物理课程案例研究 | 关梦雪 |
| 大语言模型和提示词工程在物理教学中的应用 | 郑法伟 |
| 面向AI的物理拔尖人才培养模式探索 | 吕勇军 |
| 思政教育在《大学物理(全英文)》教学中的融入与实践 | 尚江伟 |
| 科研成果融入本科量子力学教学 | 吴宁 |
| 思政背景下量子力学课程的实践 | 王锋 |
| 量子力学的可视化辅助教学设计 | 李圣文 |
| 数字赋能-物理实验课程建设与实践 | 张慧珍 |
| 从大学物理实验到现代技术实践应用的探索与创新 | 窦玲玉 |

请各负责人认真做好项目的规划与执行工作。学院将对所有立项项目进行阶段性检查。
