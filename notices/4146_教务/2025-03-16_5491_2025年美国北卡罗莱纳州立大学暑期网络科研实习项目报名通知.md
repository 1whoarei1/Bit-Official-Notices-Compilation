2025年美国北卡罗莱纳州立大学暑期网络科研实习项目报名通知

来源：教务部
发布日期：2025-03-16

一、项目介绍

美国北卡罗莱纳州立大学（North Carolina State University）成立于1887年，坐落于北卡罗莱那州的首府罗利市，是北卡州规模最大的大学，其工学院世界领先。根据美国国家科学基金会调查结果，北卡州立大学（不计算医学院）在美国所有公共机构中，产业科研费用排名第二。

该项目为期6周，由美国北卡罗莱那州立大学全球培训学院主办，通过网络的形式，由来自北卡州立大学教授和博士生悉心指导，参加项目的学生直接编入现有科研团队，完成一项小的科研任务；在项目结束时提交基于科研成果的海报演讲。
项目结束时获得项目结业证书和教授评估信。

内容详见附件1和附件2。

项目具体安排：

| 第一周 | 新生培训与研究团队见面相关文档阅读科研技术/技巧讲座开始科研项目(科研时间15-20小时)每周与教授的项目进度会 |
| --- | --- |
| 第二周 | 学术研讨会:海报演讲技巧科研项目(科研时间20-30小时)每周与教授的项目进度会 |
| 第三周 | 科研项目(科研时间20-30小时)每周与教授的项目进度会 |
| 第四周 | 学术研讨会:美国博士生研究生申请科研项目(科研时间20-30小时)每周与教授的项目进度会 |
| 第五周 | 海报演讲初稿,一对一辅导科研项目(科研时间20-30小时)每周与教授的项目进度会 |
| 第六周 | 修改完成海报演讲稿、演讲演练完成科研项目(科研时间15-20小时)网络海报演讲项目回顾总结和意见反馈颁发结业证书、教师评估信 |

二、报名条件

1. 我校全日制在读大二年级及以上本科生（不含应届毕业生）；

2. 对科研项目感兴趣；

3. 外语水平要求：提供以下任何一种英文成绩均可

TOEFL iBT：85 | CET 6: 480 | IELTS：6.5 | Duolingo： 100

4. GPA 3.0。

三、时间安排

1. 项目时间：2025年7月7日到8月15日；

2. 我校报名截止时间：2025年5月31日（北卡网站第一轮申请截止时间2025年4月16日，之后很多项目会陆续招满关闭，最终申请截止时间2025年5月31日）。

四、项目费用

1.项目费用： 1,520 美元，包括新生培训、学术讲座、实验室费用、科研项目实习费用、最终演讲、电子版结业证书、教授评估信。其他费用自理。

2. 其他费用自理。

五、报名方法

1. 参加项目的同学需登录本科生国际交流项目报名系统进行报名，同时完成美国北卡罗莱纳州立大学网上申请手续，申请网址：https://gti.ncsu.edu/gears/；

2.我校报名系统需上传：

（1）中、英文成绩单；

（2）中、英文个人简历（附照片）；

（3）英语水平相关证明材料。
