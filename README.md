# 北京理工大学公开通知整理

本仓库是对北京理工大学及其所属单位在公网发布的通知所作的非官方整理，当前收录 2941 篇通知，涉及近50个整理渠道（部分渠道失效）。内容仅用于检索、归档与学习，请以每篇文档中的原始页面为准。

## 收录范围

- 原文在采集时可通过公网访问。
- 原文链接属于 `bit.edu.cn` 官方域名体系。
- 内容为第一批成功获取的通知，并二次处理后的纯 Markdown 版本。
- 时间范围为-2023-x月x日~2026年8月19日

注意，渠道并不是一成不变的，例如原“经管”渠道似乎被拆分为“经济”和“管理”两个渠道，原经管渠道内容找不到了（猜测）。

## 未收录内容

- PDF 原文和微信公众号文章。
- 404、校园网/WebVPN、访问验证、网络失败或原文链接异常的内容。
- 公示、拟录取、评审结果、候选名单等名单或结果类内容。
- 图片抓取失败、纯图片原文及其他需要人工二次处理的内容。
